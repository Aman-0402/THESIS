4. Discussion

The empirical result across all 8 classifiers is consistent: no model's test accuracy exceeds the majority-class baseline ({{ baseline|floatformat:2 }}), and no model's ROC-AUC meaningfully exceeds 0.50. This matches the original thesis's own reported finding and should be read as evidence of limited predictive signal in the current feature set for this target, not as a failed experiment — a null result correctly obtained by a leakage-free, chronologically-split pipeline is a valid and reportable thesis finding.

Two of the eight models (Naive Bayes, SVM) collapsed to near-constant predictors, a known failure mode when class-imbalance handling (class_weight="balanced") interacts with a genuinely weak signal: if no feature actually separates the classes, the model finds no boundary better than a trivial one. This itself is informative — it suggests the active features, as currently defined, do not carry enough quarter-over-quarter predictive information about stock direction for pharmaceutical companies in this dataset.

5. Limitations

  • Feature formulas are not the original thesis's exact formulas. The exact 22 feature definitions live in an external "feature dictionary" not present in this repository; standard, documented finance formulas are used as a stated substitute.
  • 4 of 22 features are entirely absent (volume_change_60d, debt_to_equity, price_to_book, price_to_earnings_proxy) because no source file carries market_cap, total_debt, or usable volume coverage.
  • Two companies have structurally incomplete data: Laboratorios_Rovi has no daily-price data at all (zero dataset rows); Zenotech_Laboratories has no Annual/Quarterly financial statements (fundamentals always missing).
  • The financial-lag rule and target/horizon definition are pipeline-level assumptions taken from the project's own working defaults, not yet confirmed by the thesis supervisor. If the confirmed answers differ, the affected pipeline stages must be rerun and this report regenerated.
  • Dataset window is wider than originally planned (companies' real cleaned stock series often start decades earlier than the 2014 assumption) — confirmed against source data, not a defect.

6. Independent implementation review

Three items were flagged during independent technical review of the pipeline implementation. None were found to be a data-integrity or leakage failure.

YELLOW Price-basis consistency — the rule is adj_close when available, otherwise close. Recommended: confirm all 30 cleaned stock series follow a sufficiently consistent adjusted-price basis.

YELLOW Class-weight asymmetry — some classifiers use class_weight="balanced" (Logistic Regression, Random Forest, SVM, Decision Tree) while others don't, because their scikit-learn interfaces don't expose that parameter (Naive Bayes, Gradient Boosting, Neural Network, KNN). Documented in pipeline/_05_split_train.py.

RESOLVED Dependency pinning — the original project had no pinned requirements file; requirements.txt now pins every dependency version used to produce these results.

7. Conclusion

Across all 8 required classifiers, trained and evaluated under a leakage-controlled, chronologically-split pipeline (train-only imputation, validation-only hyperparameter freezing, single held-out test evaluation), none exceeds the majority-class baseline in test accuracy, and ROC-AUC values across all models cluster near the 0.50 random-classifier line. The current evidence does not support the hypothesis that the active market and fundamental features, at quarterly frequency, predict next-quarter stock direction for this 29-company pharmaceutical universe better than chance. This is reported as the pipeline's actual empirical result rather than adjusted or selectively presented.
