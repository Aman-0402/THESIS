# ML Pipeline

Reproduces the classification pipeline described in `documentation .pdf`
using the cleaned data in `YUKTHA_CLEAN_2026-09-07/`.

## Setup

```
pip install -r requirements.txt
```

## Run stages in order

```
python pipeline/_01_load_raw.py
python pipeline/_02_clean_stock.py
python pipeline/_03_build_panel.py
python pipeline/_04_features_target.py
python pipeline/_05_split_train.py
```

Outputs land in `pipeline/outputs/` (gitignored, regenerated by the scripts above):
- `raw_daily.parquet`, `raw_financial.parquet` — parsed-once caches of every company's CSVs
- `stock_clean/<company>.csv` — one canonical daily price series per company (`date`, `close`)
- `panel_quarters.csv` — company-quarter panel of dates covered by each company's stock series
- `dataset.csv` — analysis-ready panel: 22 features + binary target per company-quarter
- `predictions/<model>.csv` — held-out test-set predictions per classifier
- `metrics.json` — accuracy/precision/recall/specificity/F1/confusion matrix/ROC-AUC per model, plus the majority-class baseline accuracy

## Run tests

```
python -m pytest tests/pipeline -v
```

## Known deviations from the original thesis numbers

- **Feature formulas**: `documentation .pdf` section 12 says the exact 22 feature
  formulas live in an external feature dictionary not present in this repo.
  `pipeline/lib/features.py` uses documented standard finance formulas instead.
- **Dataset size**: the frozen thesis reports 1,410 rows (2014Q3-2026Q1). This
  pipeline produces 3,439 rows, because several companies' actual cleaned stock
  series extend back to the 1960s-1990s rather than starting at 2014 (confirmed
  against the real source data, not a bug).
- **Fundamental coverage**: `market_cap` and `total_debt` are `None` for every
  row — no source file carries either as a clean financial-statement line item
  (market cap is a market-data figure; debt only appears as cash-flow activity
  lines, not a balance). This makes `price_to_book`, `price_to_earnings_proxy`,
  and `debt_to_equity` `None` throughout, and `volume_change_60d` is also
  always `None` (no volume column survived into the cleaned stock series).
  These 4 all-NaN columns are excluded from the feature matrix passed to the
  classifiers (see `pipeline/_05_split_train.py`).
- **Laboratorios_Rovi**: has zero daily-price CSV rows in the source archive
  (no `02_MARKET_DATA/Daily/` data at all), so it contributes zero rows to the
  dataset. `Zenotech_Laboratories` similarly has zero financial-statement rows
  (only `.xlsx` files, not parsed by this pipeline), so its fundamental
  features are always `None`, though its market features still compute.

## Result

No model exceeds the majority-class baseline in test accuracy — consistent
with the original thesis's finding of limited predictive signal.
